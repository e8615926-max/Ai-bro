# Зона 51 — короткометражка из кода (ELDAR COMPANY)

Вертикальное видео 1080×1920 (9:16), 30 к/с, ~3:10, с озвучкой и субтитрами.
Готовый файл — [`zone51.mp4`](zone51.mp4). Вся картинка и все звуки сделаны программно;
голоса — нейросеть Piper (VITS), русские модели denis / dmitri / ruslan / irina, из которых сдвигом высоты
с сохранением формант получено 9 разных персонажей, эмоции заданы по отдельным словам.

## Сюжет

1. Советская квартира ночью: Андрей с кружкой пива на диване, нога закинута, рядом спит рыжий кот,
   часы идут, на стене ковёр и фото «Андрей и Саша».
2. Телевизор «Рубин» у окна с панельками; наезд в экран — «Новости дня» (эффект старого кинескопа).
3. Ведущий Эдди сообщает о взрыве Зоны 51.
4. Репортаж Элли: камера снизу, Сэм поднимает её; Сэм отходит влево и приближает ворота — там двое
   полицейских, внутрь осторожно заходят люди в химзащите и пожарные, у скорой врачи.
5. Кларкс встаёт перед Элли и запрещает съёмку; перепалка.
6. Второй взрыв: Сэм наводит камеру на огненный шар, все оборачиваются, у Элли падает микрофон,
   из огня выходят мутанты, Кларкс и полицейские стреляют, люди убегают.
7. Бегство: кровь на дороге, тело полицейского, сверху спускается человек-паук и прыгает на камеру —
   камера падает, трещина на экране, сквозь помехи крик «Сэм!», рычание, «НЕТ СИГНАЛА».
8. Студия: «Чёрт, я не могу соврать!..» → натянутая улыбка: «Это было кино!.. А теперь — реклама!»
   Реклама хлопьев «Принклс».
9. Камера отъезжает от телевизора. Андрей, кот Рыжик, Саша с рыжими волосами и родинкой,
   стук в дверь, вид в глазок, мама Саши с пирогом… «Дело в том, что у меня нет мамы…»
   Продолжение во 2 части.

## Файлы

| Файл | Что делает |
|---|---|
| `lines.py` | реплики, субтитры, голоса персонажей, эмоции по словам |
| `tts.py` | синтез Piper + rubberband, огибающая для анимации рта |
| `timeline.py` | монтаж: время планов, реплик и событий считается из длины озвучки |
| `human.py`, `cast.py` | риг персонажей (вид спереди/сзади/сбоку, моргание, взгляд, рот, ИК рук, походка) и их внешность |
| `room.py`, `scene_room.py` | квартира, кот, часы, Андрей и Саша, поворот камеры к проёму |
| `hall.py` | прихожая, дверь с глазком, вид через глазок, мама Саши, туалет |
| `tvroom.py`, `studio.py`, `ad.py` | телевизор у окна, студия новостей, реклама хлопьев |
| `zone.py`, `field.py`, `actors.py` | Зона 51: огонь, дым, машины с фарами, взрыв, полиция, химзащита, мутанты, человек-паук |
| `post.py` | эфирная графика, субтитры, старый кинескоп, трещина, помехи, водяной знак |
| `audio.py` | звук: заставка, сирены, огонь, взрыв, выстрелы, рык, реклама, стук в дверь, сведение |
| `render.py` | покадровый рендер на всех ядрах с передачей кадров в ffmpeg |

Сборка: `./build.sh`. Отдельные кадры: `python3 render.py --preview 14,52,80`.
