# Зона 51 — короткометражка из кода

Вертикальное видео 1080×1920 (9:16), 30 к/с, ~1:43, с озвучкой и субтитрами.
Готовый файл — [`zone51.mp4`](zone51.mp4). Всё нарисовано и озвучено программно:
ни одной сторонней картинки, видео или звукового файла.

## Сюжет по планам

1. Советская квартира ночью: Андрей в спортивном костюме сидит на диване, закинув ногу,
   рядом спит рыжий кот, на стене ковёр и фото «Андрей и Саша». Свет только от телевизора.
2. Старый телевизор «Рубин» на фоне ночного окна с панельками, луной, шторами и фикусом;
   камера наезжает в экран, где начинается заставка «Новостей дня».
3. Студия: ведущий Эдди в смокинге (губы двигаются по громкости голоса) объявляет о взрыве.
4. Прямой эфир у Зоны 51: горящая база, полицейские машины с мигалками, ограждение.
   Камера сначала снизу (лица Элли не видно), Сэм поднимает её; Элли в контровом свете.
5. Элли и Сэм идут к базе, полицейский Кларкс преграждает путь, перепалка.
6. Новый взрыв, из огня выходят мутанты, Кларкс стреляет, паника.
7. Бегство, на Сэма прыгает человек-паук — помехи, «НЕТ СИГНАЛА», «ЭФИР ПРЕРВАН».
8. Снова комната Андрея — телевизор шипит.

## Как устроено

| Файл | Что делает |
|---|---|
| `lines.py` | реплики, тексты субтитров и голоса персонажей |
| `tts.py` | синтез речи RHVoice, огибающая громкости для анимации рта |
| `timeline.py` | монтаж: планы и время каждой реплики считаются из длины озвучки |
| `room.py`, `tvroom.py`, `studio.py`, `zone.py` | декорации; огонь и дым — процедурный шум |
| `actors.py` | персонажи (Элли, Кларкс, полицейские, мутанты, человек-паук) |
| `field.py` | планы репортажа: камера, тряска, контровой свет, взрыв, выстрелы |
| `post.py` | эфирная графика, субтитры с подсветкой слова, помехи, кинескоп, зерно |
| `audio.py` | звук: заставка, сирены, огонь, взрыв, рык, выстрелы, помехи, сведение |
| `render.py` | покадровый рендер на всех ядрах с передачей кадров в ffmpeg |

Сборка: `./build.sh` (нужны `python3` с numpy/pillow/scipy, `ffmpeg`, `rhvoice` и `rhvoice-russian`).
Просмотр отдельных кадров: `python3 render.py --preview 14,52,80`.
