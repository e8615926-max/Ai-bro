## 🧸 Тряпичная Песочница (`sandbox.html`)
Физическая песочница с тряпичными куклами: открой `sandbox.html` в браузере (работает и на телефоне).
- Манекены пытаются стоять, получают урон от ударов, теряют конечности, оживают от шприца.
- Предметы: ящик, доска, бетон, мяч, гиря, бомба, взрывная бочка, шипы, платформа.
- Инструменты: рука, нож, взрыв, гвоздь, лечение, удаление; пауза, замедление, невесомость.
- Клавиши: `Пробел` — пауза, `1–6` — инструменты.
